# Decision register guide (package template)

**Français :** [README.fr.md](README.fr.md)

This folder is where the **governed repository** records its own architecture decision records (ADRs). It intentionally contains no GovCheck decisions.

Conventions:

1. Number ADRs sequentially: 0001-<slug>.md, with a French counterpart 0001-<slug>.fr.md. English is the default language.
2. Start each ADR with a status line: proposed / accepted / deprecated / superseded.
3. Use the provided [TEMPLATE.md](TEMPLATE.md) ([version française](TEMPLATE.fr.md)).
4. Record context, decision, consequences; link related architecture records.
