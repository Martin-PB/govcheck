# Guide du registre de décisions (gabarit du package)

**English:** [README.md](README.md)

Ce dossier est où le **dépôt gouverné** consigne ses propres ADR. Il ne contient volontairement aucune décision de GovCheck.

Conventions :

1. Numérotez les ADR séquentiellement : 0001-<slug>.md, avec une version française 0001-<slug>.fr.md. L'anglais est la langue par défaut.
2. Commencez chaque ADR par une ligne de statut : proposed / accepted / deprecated / superseded.
3. Utilisez le [TEMPLATE.md](TEMPLATE.md) ([version française](TEMPLATE.fr.md)).
4. Documentez le contexte, la décision, les conséquences ; reliez les records d'architecture associés.
